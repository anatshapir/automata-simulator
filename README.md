# סימולטור אוטומטים

סביבה לבנייה ולהרצה של אוטומטים סופיים לתלמידי י״א במגמת מדעי המחשב (899271): אסד״מ, אס״ד לא מלא וא״ס לא דטרמיניסטי, בעברית ובסימונים של הכיתה.

**האתר:** https://anatshapir.github.io/automata-simulator/

## מה יש

- בנייה בציור ובטבלה (מסונכרנים), שלשות, הגדרה פורמלית ומקרא "מה המצב זוכר".
- בדיקת תקינות עם קטלוג המשוב F-01 עד F-10, כולל כלל הקדימות F-07/F-03.
- הרצה צעד אחר צעד, אחורה וקדימה, עם הסבר תוצאה (F-12 עד F-16); בא״ס קבוצת מצבים ועץ חישוב עם כלל 16 העלים.
- כלי עזר T-1 עד T-9, משימה בתוך הקובץ עם מילות בדיקה, מצב מורה ומצב הצגה מול כיתה.
- שמירה וטעינה של קובץ `.automaton.json`, טיוטה אוטומטית בדפדפן, ייצוא ציור ל-SVG ול-PNG.
- 31 דוגמאות מאומתות מהחומרים (תפריט "דוגמאות").

מקור הדרישות: מסמך האפיון v1.9. הקובץ בנוי בדיוק לפי סכימת הקובץ שבסעיף 10.2.

## פיתוח

```bash
npm install
npm run typecheck
npm test        # כל ה-fixtures, 14 מקרי התקינות ומקרי הקלט
npm run dev     # שרת מקומי
npm run build   # אתר סטטי בתיקייה dist
```

כל דחיפה ל-`main` מריצה את הבדיקות ומפרסמת ל-GitHub Pages.

בדיקות הקבלה של הממשק (צריך Python עם Playwright):

```bash
npm run build && npx vite preview --port 4173 &
python3 tests/ui/ui_acceptance.py http://127.0.0.1:4173/
```

דוח קבלה מלא (כל 38 התנאים, עם פקודות, תוצאות ותאריך): [`docs/acceptance-report.md`](docs/acceptance-report.md). נוצר מחדש עם `python3 tools/acceptance_report.py`.

## מבנה

| תיקייה | תוכן |
|---|---|
| `src/model` | מודל האוטומט (= סכימת הקובץ) |
| `src/validation` | כללי תקינות וקטלוג המשוב |
| `src/engine` | הקלדת מילה, הרצה, עץ חישוב |
| `src/analysis` | כלי העזר T-1 עד T-9 |
| `src/editor` | ציור, טבלה ופעולות עריכה |
| `src/export` | קובץ, טיוטה, SVG/PNG |
| `src/app` | המסכים |
| `tests/fixtures` | חבילת הבדיקות הרשמית; נבנית על ידי `tools/build_fixtures.py` ו-`tools/build_validation.py` |

אין לערוך את קובצי ה-fixtures ביד. שינוי בהם נעשה בסקריפטים, ושתי בניות נותנות קבצים זהים.
